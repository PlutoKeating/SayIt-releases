# 你讲 SayIt — Releases

「你讲」（SayIt）Android 版的安装包发布处。源码不公开；本仓库只承载 Release 附件。

- 官网与下载页：https://sayit.plutokeating.beer/download
- 每个版本附 `sayit-<version>-<abi>.apk`（真机用 `arm64-v8a`）与 `SHA256SUMS.txt`。

Release artifacts for SayIt (你讲), the Android app. Source is not public; this repository only hosts release assets.

- Site and download page: https://sayit.plutokeating.beer/en/download
- Each release ships `sayit-<version>-<abi>.apk` (use `arm64-v8a` on phones) and `SHA256SUMS.txt`.
- Requires Android 10 (API 29) or newer.
